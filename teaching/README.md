# teaching

The teaching pack, built from this repository, for a 90-minute post-graduate session on **OWASP LLM in Practice**.

- `slides/` — 15-25 slides
- `lab/` — hands-on lab sheet (trainee performs against this repo), expected outputs, ≥3 stretch challenges, answer key
- `assessment-map/` — learning outcomes and assessment mapping
- `common-trainee-mistakes.md` — 5 predicted misconceptions and how to correct each
